Held-Out Test Set Performance & Latency Benchmark

Strict Evaluation

The live service runs the TF-IDF + Logistic Regression model (trained on the full Tobi-Bueck/customer-support-tickets English set) with the ITIL cue correction. Measured on the held-out test split (3,563 tickets) and on hand-written tickets:

Model Accuracy Macro-F1 Weighted-F1 Hand-written holdout Auto-accept precision P50 / P95 Latency
TF-IDF + LR + ITIL cues Live 0.8532 0.8618 0.8549 79% 94.8% (66% auto-accepted) 0.81 / 1.73 ms
TF-IDF + LR (model only) 0.8695 0.8763 0.8700 38% 96.4% (65% auto-accepted) 0.76 / 1.74 ms
DistilBERT (LoRA / PEFT) historical quick run, not deployed 0.4444 0.3273 0.3816 — — 13.32 / 14.92 ms

The dataset is long-form and synthetic; ITIL cues trade ~1.5 Macro-F1 points on it for a large gain on short, real-world tickets (24-ticket holdout, so treat as indicative). DistilBERT needs >512 MB RAM and is not served on the Render free tier.

Deploying TicketLens to Render Cloud

Turnkey Blueprint

Deploying TicketLens to Render is turnkey using either the Render Blueprint (render.yaml) or the Docker container:

Option A: 1-Click Render Blueprint (Recommended)

  1. Log in to your Render Dashboard (dashboard.render.com).
  2. Click New + → Blueprint.
  3. Connect your GitHub repository: https://github.com/Charanloyal/ticketlens.
  4. Render will automatically detect render.yaml and provision your Web Service!

Option B: Manual Render Web Service Setup

Environment Python 3.11 or Docker
Build Command pip install -r requirements-render.txt && PYTHONPATH=src python -m ticketlens.train_baseline --mode all --require-dataset
Start Command uvicorn main:app --host 0.0.0.0 --port $PORT --proxy-headers --forwarded-allow-ips='*'
Health Check Path /health
Environment Variables PYTHON_VERSION=3.11.9 · TICKETLENS_ENV=production · PYTHONPATH=src:.
Instance Type Free (512 MB) — server runs in ~220 MB; sleeps when idle

render.yaml Blueprint Spec

services: - type: web name: ticketlens runtime: python buildCommand: "pip install --upgrade pip && pip install -r requirements-render.txt && PYTHONPATH=src python -m ticketlens.train_baseline --mode all --require-dataset" startCommand: "uvicorn main:app --host 0.0.0.0 --port $PORT --proxy-headers --forwarded-allow-ips='*'" healthCheckPath: /health envVars: - key: PYTHON_VERSION value: 3.11.9 - key: TICKETLENS_ENV value: production
